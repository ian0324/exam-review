## 功能

- 依科目、依主題分開的問答式重點整理
- 三種複習模式：全部顯示／遮答案／只遮數字
- 依主題分開的小測驗，自評後記錄常錯題
- 錯題本依科目隔離，常錯的題目下次優先出題

作答紀錄以 localStorage 存在瀏覽器本機，不會上傳。頁面內附匯出／還原字串可跨裝置搬移。
